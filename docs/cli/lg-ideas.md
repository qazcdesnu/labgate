# lg ideas

ideation 프로젝트의 아이디어 후보를 **잠근 평가 기준**으로 비교한다: 후보 × 기준 점수, 가중 평균, 순위, 결격. **읽기만 한다.**

- 누가: 사람, 에이전트 모두
- 언제: 후보를 평가한 뒤, 방향을 고르는 게이트를 판정하기 전 (`lg answer`에서 고를 후보를 묻기 전에 보면 좋다)
- 전제: `lg init --kind ideation`으로 만든 프로젝트(spec_version 7 이상, `plan/criteria.md`가 있다)

## 형식

```
lg ideas [--json]
```

## 인자와 옵션

| 이름 | 값 | 기본값 | 설명 |
|---|---|---|---|
| `--json` | — | 꺼짐 | 같은 내용을 JSON으로 출력한다 |

## 계산

- **기준:** `plan/criteria.md`의 `## 기준` 표 (`ID | 기준 | 묻는 것 | 누가 | 가중치 | 결격`).
- **점수:** 후보마다 `ideas/I<n>_<slug>.md`의 `## 평가 (기준 <커밋>)` 표(`기준 | 점수 | 근거 | 확신`).
- **가중 평균:** 근거가 있는 점수와 사람이 매긴 점수의 가중 평균이다(1–5). 근거 없는 점수는 무효라 빠진다. 합계와 순위는 이 명령이 계산한다. 에이전트가 손으로 더하거나 순위를 매기지 않는다.
- **결격:** 결격 조건이 있는 기준에서 1점이면 결격이다. 순위에서 빠진다.
- **순위에서 빼는 평가:**
  - 기준이 잠기기 전의 평가, 기준이 바뀐 뒤 다시 매기지 않은 평가
  - 앵커(`plan/anchor.md`)가 잠기기 전의 평가, 앵커가 바뀐 뒤 다시 쓰지 않은 평가
  - `## 앵커 대비` 절이 없는 후보 (spec_version 8 이상)
  - `## 앵커 대비`에 앵커 `## 한계`의 `L<n>`이 하나도 없는 후보 (앵커가 무엇에 대한 기여인지의 기준점이다)
- **버전:** 평가 표 머리 `## 평가 (기준 <기준 버전>, 앵커 <앵커 버전>)`의 두 커밋은 이 명령이 맨 위에 보여 준다. 각 문서의 내용을 마지막으로 바꾼 커밋이고, 잠금 반영처럼 `status`·`locked_commit`만 바꾼 커밋은 세지 않는다.

## 표시

| 표시 | 뜻 |
|---|---|
| `!` | 근거 없는 점수 (무효) |
| `?` | 확신 "하" |
| `·` | 아직 없음 (사람 기준 포함) |
| `결격` | 결격 조건에 걸림 |

표 아래 "확인할 것"에 후보별 문제를 적는다: 잠기기 전 평가, 기준 변경 전 평가, 평가하지 않은 기준, 기준 문서에 없는 기준, 1–5 밖의 점수, 근거 없는 점수.

방향은 사람이 정한다. 순위와 다르게 고르면 이유를 남긴다(`lg answer`의 코멘트, `brief.md`의 "왜 이 방향인가").

자세한 사양: 설계 문서 §26.6.

## 읽고 쓰는 것

- 읽는 것: `plan/criteria.md`, `plan/anchor.md`, `ideas/I*_*.md`, 두 문서의 커밋 이력
- 쓰는 것: 없음

## 종료 코드

| 코드 | 의미 |
|---|---|
| 0 | 출력함 |
| 1 | 예기치 못한 오류 |
| 2 | labgate 프로젝트가 아님, `plan/criteria.md`가 없음 (ideation 프로젝트가 아님) |
| 4 | Git 오류 |
| 130 | 중단(Ctrl-C) |

## 예

```
$ lg ideas
평가 기준: plan/criteria.md (locked) · 기준 버전 3f2a1c9 · 후보 4개
앵커: shen2025-codi · GSM8K · accuracy 43.7 (Table 2) (locked) · 앵커 버전 8b0d4e2
  앵커의 한계: L1, L2, L3 (후보는 ## 앵커 대비에 푸는 한계를 적는다)
  평가 표 머리: ## 평가 (기준 3f2a1c9, 앵커 8b0d4e2)

  ID  상태       C1×3  C2×3  C3×2  C4×2  C5×2  C6×2  C7×1  C8×2(사람)  평균  순위
  I1  candidate  2     3     3     3     3     3     3     (사람)      2.80  3
  I2  candidate  5     4     4     4     4     4     4     (사람)      4.20  1
  I3  candidate  1     5     5     5     5     5     5     (사람)      결격
  I4  candidate  4     5!    4     4     4     4     4     (사람)      4.00  2

평균: 근거가 있는 점수의 가중 평균. 결격: 결격이 있는 기준에서 1점. !: 근거 없는 점수(무효), ?: 확신 하, ·: 아직 없음

확인할 것:
  I4: C2: 근거 없는 점수 (무효)
방향은 사람이 정합니다. 순위와 다르게 고르면 이유를 남기세요 (lg answer 코멘트, brief.md).
```
